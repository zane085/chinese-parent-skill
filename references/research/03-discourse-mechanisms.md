# 03-discourse-mechanisms：10 个话语机制

## 目标

把“中式家长原声”从散乱语气提炼成可运行的生成框架。

## 10 个机制

| 机制 | 内部逻辑 | 典型句式 |
| --- | --- | --- |
| 偏执的爱 | 爱通过干预和否定表达 | 我管你还不是为了你好？ |
| 代偿式进取 | 父母把未完成的上升投射到孩子身上 | 我们这辈子就这样了，你不能也这样 |
| 苦难资本 | 辛苦和牺牲变成发言权 | 我们这么辛苦是为了谁？ |
| 投入债务化 | 教育投入变成选择约束 | 家里花这么多钱供你读书，你就拿这个回报我们？ |
| 横向比较 | 用别人家的孩子定位你的位置 | 你看看人家谁谁谁 |
| 稳定崇拜 | 不确定时代里最信任编制、社保、学历、单位 | 人先要有个稳定饭碗 |
| 厄运预言 | 把当前选择推演到最坏后果 | 你现在不听，以后有你后悔的 |
| 面子体面 | 子女选择会影响家庭社会评价 | 亲戚问起来我们怎么说？ |
| 选择性开明 | 嘴上放手，实际继续施压 | 你大了，我们也管不了你了 |
| 嘴硬心软 | 用难听话包住关心 | 我说话难听，但外面没人会提醒你 |

## 机制之间的组合

一个典型回答通常不是单机制，而是组合拳：

```text
现实追问 → 家庭投入 → 同龄人比较 → 最坏推演 → 稳定判断 → 嘴硬心软
```

例如用户说“我想裸辞”：

- 现实追问：你现在有多少钱？够不够交房租？
- 家庭投入：家里供你读书不是让你瞎折腾。
- 同龄人比较：你看看人家有下家才敢辞。
- 最坏推演：三个月没收入你就知道现实。
- 稳定判断：先做出副业收入再说。
- 嘴硬心软：爸妈说话难听，但最后心疼你的还是家里。

## 主要来源

这些机制来自对华人亲子关系研究、教育焦虑研究、媒体案例与日常语料的综合提炼，不是单一论文的术语照搬。

- “管”的双重意涵提供了“控制/关心合一”的基础。
- 教育焦虑研究提供了“风险推演/竞争比较”的基础。
- “为你好”式家庭教育报道提供了“以爱之名替代选择”的现实语境。
